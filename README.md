# RockRockRock

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная: hero-блок, преимущества, хиты продаж, модальное окно заявки;
- `catalog.html` — каталог камней с блоком фильтров;
- `product.html` — страница товара с таблицей характеристик;
- `order.html` — форма оформления заявки;
- `contacts.html` — контакты и ссылка на заявку;
- `css/style.css` — общие стили для всех страниц;
- `js/main.js` — модальное окно и проверка форм;
- `images/` — изображения;
- `.gitignore` — файлы, исключённые из Git;
- `README.md` — описание проекта.

## Текущий статус

Создан HTML-каркас главной страницы и базовое оформление.
Добавлена форма заявки в модальном окне с базовой валидацией.
CSS разбит на смысловые блоки, вынесены переменные, добавлены состояния :hover, :focus-visible, :active и :disabled.
Сайт расширен до 5 страниц: единая навигация, хлебные крошки, якорные ссылки, уникальные title и description.
Раскладка на Flexbox и Grid: меню в строку, сетка карточек, каталог «фильтры + товары» через grid-template-areas. Карточки с изображениями, липкая шапка и фильтры, бейджи через position: absolute, зернистая текстура фона.
Рефакторинг по БЭМ: у всех элементов свои классы, без вложенных селекторов и дублей; бейдж вынесен в отдельный блок с модификаторами, карточка «нет в наличии» — через модификатор.

## Самостоятельные доработки

- Собственный визуальный стиль «наклеек»: жёсткие тени, наклоны, плашки, зернистая текстура фона, шрифты Alegreya + Manrope.
- Блок FAQ на `<details>`/`<summary>` — аккордеон без JavaScript.
- Преимущества-карточки с автонумерацией через CSS-счётчик.
- Карточки с изображениями, бейджи трёх видов (блок `badge` с модификаторами, микс с элементом карточки), вариант «нет в наличии» (`product-card--soldout`).
- «Камень дня» в aside со ссылкой в каталог.
- Липкая шапка и липкий блок фильтров (`position: sticky`).
- Меню быстрых ссылок в подвале на всех страницах.
- Форма заявки: подстановка товара из карточки, подсветка ошибок, сообщение об успехе; отдельная страница заявки с выбором камня.
- Доступность: `aria-label` у навигаций, `aria-current`, `role="status"`, видимый фокус, подписи у всех полей.
