Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

- `index.html` — главная страница;

- `js/main.js` — открытие и закрытие модального окна, проверка формы;

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Цель — разработать многостраничный сайт интернет-магазина без CSS-фреймворков.

Обязательные страницы:

- `index.html` — главная: hero-блок, преимущества, популярные товары;
- `catalog.html` — каталог товаров с категориями и фильтрами;
- `product.html` — карточка товара с таблицей характеристик;
- `order.html` — форма оформления заявки;
- `contacts.html` — контакты и форма обратной связи.

Обязательные элементы: семантическая разметка, единая навигация, якорные ссылки, карточки товаров, таблица, форма, модальное окно, CSS-переменные, состояния `:hover` и `:focus-visible`, Flexbox и Grid, БЭМ, позиционирование.
