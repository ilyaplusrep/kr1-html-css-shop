# RockRockRock

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная: hero-блок, преимущества, хиты продаж, модальное окно заявки;
- `catalog.html` — каталог камней с блоком фильтров;
- `product.html` — страница товара с таблицей характеристик;
- `order.html` — форма оформления заявки;
- `contacts.html` — контакты и ссылка на заявку;
- `css/style.css` — общие стили для всех страниц;
- `js/main.js` — модальное окно и проверка форм;
- `images/` — изображения;
- `.gitignore` — файлы, исключённые из Git;
- `README.md` — описание проекта.

## Используемые технологии

- HTML;
- CSS;

## Текущий статус

Создан HTML-каркас главной страницы и базовое оформление.
Добавлена форма заявки в модальном окне с базовой валидацией.
CSS разбит на смысловые блоки, вынесены переменные, добавлены состояния :hover, :focus-visible, :active и :disabled.
Сайт расширен до 5 страниц: единая навигация, хлебные крошки, якорные ссылки, уникальные title и description.
Раскладка на Flexbox и Grid: меню в строку, сетка карточек, каталог «фильтры + товары» через grid-template-areas. Карточки с изображениями, липкая шапка и фильтры, бейджи через position: absolute, зернистая текстура фона.

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Цель — разработать многостраничный сайт интернет-магазина без CSS-фреймворков.

Обязательные страницы:

- `index.html` — главная: hero-блок, преимущества, популярные товары;
- `catalog.html` — каталог товаров с категориями и фильтрами;
- `product.html` — карточка товара с таблицей характеристик;
- `order.html` — форма оформления заявки;
- `contacts.html` — контакты и форма обратной связи.

Обязательные элементы: семантическая разметка, единая навигация, якорные ссылки, карточки товаров, таблица, форма, модальное окно, CSS-переменные, состояния `:hover` и `:focus-visible`, Flexbox и Grid, БЭМ, позиционирование.
